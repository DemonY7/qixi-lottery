# 七夕幸运抽奖

一个用于微信扫码的七夕主题抽奖网页。

## 抽奖规则

- 每人 5 次机会
- 奖品及概率：
  - 谢谢参与：15%
  - 20 元红包：30%
  - 50 元红包：25%
  - 100 元红包：15%
  - 彩票 1 张：10%
  - 彩票 2 张：4%
  - 彩票 3 张：1%

## GitHub Pages 部署步骤

1. 在 GitHub 新建仓库，命名为 `qixi-lottery`
2. 把本文件夹内 `index.html`、`.nojekyll`、`README.md` 上传到仓库根目录
3. 进入仓库 Settings → Pages
4. Source 选择 Deploy from a branch，Branch 选 `main` / `root`
5. 等待 1-3 分钟，访问 `https://demony7.github.io/qixi-lottery/`
